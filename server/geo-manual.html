GEO 人工录入

路径 C · 透镜GEO 免费版验证通道

这是什么

你已在 timus.ai（透镜GEO） 免费版看到品牌在各大 AI 引擎的真实排名。把结论回填到这里， 系统就会把真实数据落盘到 GEO 工作台（收录覆盖、关键词排名、趋势图都会更新）。
本通道不调用任何上游 API（免费版不开放接口），纯人工录入，数据 100% 来自你看到的报告。

操作流程

1) 打开 timus.ai → 注册免费版 → 添加品牌名 / 核心词 → 查看「AI 排名透视」报告；
2) 在下方填入关键词，并按报告把每个引擎的排名填进来（0 = 未收录，1~50 = 第几位）；
3) 点「提交录入」→ 去系统 GEO 工作台 看实时看板。
